# 🎓 Student Performance Predictor

A Machine Learning project that predicts a student's **final exam score** using academic and lifestyle-related factors.

## 🧠 About the Project

The model analyzes factors such as:

* 📚 Study hours
* 📊 Attendance percentage
* 📝 Previous exam score
* 😴 Sleep hours
* ✅ Assignments completed

and uses **Linear Regression** to predict the expected final score.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/RajeshNeural/student-performance-predictor.git
cd student-performance-predictor
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Run:

```bash
python predictor.py
```

The program will:

1. Load the student dataset
2. Train the Linear Regression model
3. Evaluate the model
4. Predict a student's final score
